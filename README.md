# classic_games

A series of classic games

# Available games
* 15 game
  * reorder a grid from 1 to 15
* Hangman
  * guess the word
* Mastermind
  * break the secret code
* Memory
  * find all pairs
* Minesweeper
  * avoid all mines
* Tris
  * make a tris horizzontally, vertically or diagonally
