# classic_games

A series of classic games

# Available games
* 15 game
  * reorder a grid from 1 to 15
* Hangman
  * guess the word
* Hanoi Tower
  * move all discs from column A to column C
* Mastermind
  * break the secret code
* Memory
  * find all pairs
* Minesweeper
  * avoid all mines
* Simon
  * repeat the sequence
* Tris
  * make a tris horizzontally, vertically or diagonally
